# IPL tracker — working scope and limits

Based on `feature/ai-routine-consultant`. The existing UI is extended with one drawer destination and a link from the Beauty AI panel. Device registration, per-area sessions, dates, recorded settings, reactions, notes, completed/planned/missed/cancelled states, editing, postponement, preview and explicit confirmation work locally. Selected-date calendar details include noncancelled IPL sessions. Progress is session counts per area, not an efficacy or medical outcome claim. Duplicate area/date entries are rejected; editing retains session IDs. No automatic rescheduling or interval shortening occurs.

IPL uses new localStorage key `beautyspace-ipl-v1`, with validated version 1 records; existing keys, IndexedDB and calendars are unchanged. Corrupt records are retained and errors displayed. IPL has its own validated export/restore with a separate replace confirmation. Existing version 4 journal backups do not include IPL; export both archives. Settings/reactions/notes remain local. The IPL interview is deliberately not sent to the skincare AI endpoint.

**Device-specific automated IPL scheduling is unavailable.** No exact device/model or official manual was supplied, and no reviewed manufacturer schedule has been added. `manufacturerGuidance` is empty; arbitrary URLs, user-entered instructions, generic intervals and AI outputs cannot authorize dates. The planning entry asks for device history, last date, skin/hair traits, tanning, irritation, photosensitizing substances, contraindications and existing routine, then explains the manual fallback. No universal intervals, settings, discontinuation windows or safety rules are invented. This is a functional tracker and a guarded planning entry, not a completed AI treatment scheduler.

To enable a device later: verify official model/market/manual edition, permitted areas, suitability and contraindications, source rights, schedule phases and minimum intervals; implement the exact schedule with clinician/manufacturer review and tests covering missed/rescheduled sessions and each restriction. Unknown contraindications must still block planning. A generic numeric interval alone is insufficient. Any AI explanation must reference that reviewed source and pass deterministic schedule validation before an editable preview and explicit calendar confirmation. The present skincare AI cannot write IPL records.

No live AI request, IPL device test, treatment recommendation or real iOS Safari test was performed. See the delivery report for executed automated checks and screenshots.
