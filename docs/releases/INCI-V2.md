# Ingredient Check v2

Second stacked branch; base `feature/luxury-visual-polish`. There is one input for the full INCI list or a partial ingredient-name query. Suggestions share that input. Lists normalize case, Unicode width, spacing, numbering, aliases and parenthetical names; lookup is indexed rather than repeatedly scanning 28k records. Unknown names remain unknown.

The names catalog is imported from BEAUTEE's MIT-licensed lite dataset at commit `ad1d9afad3f1a721873878b83fbd9f674d628c9e`. Copyright/license are in `data/BEAUTEE-LICENSE.txt`; source hash, date, provenance and limits are in `data/source-lock.json`. Rebuild with `python3 scripts/import-inci.py --source /path/to/pinned/ingredients.json`, or allow the script to fetch that immutable source with TLS and checksum verification. It does not scrape descriptions or ratings. The publisher supplies CosIng/CAS identifiers; these were not independently revalidated against the currently network-blocked EU service. Names include common and technical names; recognition is not regulatory approval or a safety judgment.

`data/ingredient-names.json` is separate from `data/comedogenicity.json`. The latter intentionally has no live numeric rows: no attributable numeric study dataset was established. Every ungraded ingredient explicitly shows «Недостаточно данных». No zero, fragrance-derived acne score or finished-product safety verdict is inferred. A numeric row must have an integer 0–5, evidence grade, model, method, concentration and attributable reviewed HTTPS source. Tests use clearly synthetic evidence only to exercise this path. Clinical review remains necessary before adding real numeric rows.

Legacy descriptive notes and user data are retained. Product reports use the same reference as the main analyzer. The catalog and fonts work offline after worker activation. Sources and licenses ship with the static build. Required official-source/API destinations were saved in the environment draft, but not applied to the live machine; the public licensed GitHub source was usable independently.
