# Luxury visual polish

First of four stacked delivery branches, based on main `febd312`. Adds an original, specially generated still-life hero (no people), self-hosted SIL OFL Montserrat fonts, photographic treatment in the calendar/hair/INCI surfaces, quieter mobile alignment, translucent arrows and restrained press interactions. The glass navigation, reduced-motion rules and user storage schemas remain intact. Existing supplied archive files are unchanged.

The original image is retained in the execution workspace; the encoded JPEG and font license/provenance ship in `assets/`. No third-party stock photo was copied. User image references were not present among accessible attachments, so no claim of an exact reference match is made.

Validation commands and final stacked release results are recorded in the final delivery report. Actual iPhone/Safari validation requires a device or installed WebKit runtime; viewport checks alone do not establish that.
