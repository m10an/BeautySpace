## User journeys

| Journey                    | Entry / inputs                                                                               | Validation and states                                                                                                       | Cancel / completion                                                                                                                  |
| -------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| First visit / discovery    | Home, Open today, shelf/consultant/tour links                                                | Actual empty and saved states; source errors never produce an invented quote                                                | Help closes back to the same page; brand always Home                                                                                 |
| Product → INCI → save/edit | My Products, name\*, category selection, optional brand/photo/INCI                           | Original type/size/length validation, whitespace errors, IndexedDB failure recovery; local category/search filters          | Failed save retains fields; Cancel edit restores add mode; Delete confirms; results stay on shelf                                    |
| Consultant                 | Consultant/launcher, optional interview, start date\*                                        | Per-step validation, transparent local rules, overlap/medical warnings, editable validated preview, duplicate detection     | Back retains inputs; Close/Reject never writes; explicit reviewed confirmation appends and closes dialog; calendar remains reachable |
| IPL                        | Device brand*/model*, manual session date*/area*, optional recorded settings/reactions/notes | Original date/status/duplicate rules; no unverified manufacturer plan, visible preview before saving                        | New session resets draft; edit/postpone/cancel goes through preview+confirmation; existing calendar/history updates                  |
| Routine completion         | My Routine AM/PM, selected date, original task checkbox                                      | Original storage error rollback and check IDs; actual progress denominator                                                  | Checkbox action updates existing state, persists on reload; other periods/history remain unchanged                                   |
| Offline / recovery         | Cached shell and local tools                                                                 | Manual/free-local tools remain available, no network required for daily quote; source/store/network errors shown truthfully | Export both archives before switching devices; failed actions retain existing records and entered fields                             |
