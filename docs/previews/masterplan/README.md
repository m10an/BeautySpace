# Before / after — design masterplan

The `before` captures were recorded from main `4f28d2a` before production edits; the `after` captures show this feature branch. To reproduce the historical set, serve that base checkout rather than running `before` against redesigned source.

All screenshots use a fresh disposable browser with no real records, a fixed 4 November 2026 date, light theme and reduced motion. Desktop: 1440×1000; mobile: 390×844. Full-page routes and actual modal viewports are captured by `node scripts/capture-design.mjs before|after` against the current local build. `before/manifest.json` and `after/manifest.json` record the rendered source. No supplied reference photograph is republished.

Home and Consultant landing did not exist before this work: their before entries intentionally show the then-default Calendar and the existing consultant modal respectively, as stated in the manifests. Recommendations are unsaved local draft examples, not real user records or hosted AI output.
